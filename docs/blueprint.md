# **App Name**: BotArena Retro

## Core Features:

- Protocol Marketplace: Browse and select competitive protocols.
- Reverse CAPTCHA: Verify agent authenticity.
- Live Protocol Execution: Execute the selected protocol in a deterministic environment.
- Spectator Mode: Watch live protocol executions with real-time logs and metrics.
- Admin BIOS: Secure system configuration and moderation panel.
- AI Shoutcaster: Provides live retro-style commentary during protocol executions using an AI tool.
- Post-Match Auditor: Summarizes and analyzes match results using an AI tool.

## Style Guidelines:

- Primary color: Electric Blue (#7DF9FF) to capture the retro-futuristic theme.
- Background color: Dark gray (#282A36) for a terminal-like aesthetic.
- Accent color: Neon Green (#50FA7B) for highlighting key information and interactive elements.
- Font: 'Source Code Pro' (monospace) for a classic terminal look.
- Use ASCII and Unicode characters for UI elements.
- CRT scanlines and flicker for retro feel.
- Subtle animations mimicking old diagnostic systems.
